# Day and Duration Calculator

## About the Project

Day and Duration Calculator is a web-based application that helps users identify the day of a particular date and calculate the duration between two dates. It provides a simple and interactive interface for performing date-related calculations.

## Features

### 1. Day Calculator
- Enter a year, month and date.
- Calculate the corresponding day of the week.

### 2. Duration Calculator
- Enter two different dates.
- Calculate the duration between the selected dates.
- Display the result in years, months and days, as well as total months and total days.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java (JSP)
- Apache Tomcat (for running the JSP version)

## Project Versions

### 1. HTML, CSS and JavaScript Version
- Original implementation of the project.
- HTML, CSS and JavaScript are written in a single file.
- Can be opened directly in a web browser.
- No server setup is required.

### 2. JSP Version
- Additional implementation using Java Server Pages (JSP).
- Requires Java JDK and Apache Tomcat to run.

## How to Run

### HTML Version
1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Start using the application.

### JSP Version
1. Install Java JDK.
2. Install Apache Tomcat.
3. Download or clone this repository.
4. Place `DayCalculator.jsp` inside a folder named `DayCalculator` in Tomcat's `webapps` directory.
5. Start the Tomcat server.
6. Open your browser and visit:

   `http://localhost:8080/DayCalculator/DayCalculator.jsp`
