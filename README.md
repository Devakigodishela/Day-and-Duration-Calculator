# Day and Duration Calculator

## About the Project
Day and Duration Calculator is a web-based application developed using HTML, CSS and JavaScript. It helps users find the day of a particular date and calculate the duration between two dates.

## Features
- **Day Calculator:** Finds the day of the week for a given date.
- **Duration Calculator:** Calculates the number of days between two selected dates.
- Simple and user-friendly interface.
- Instant calculation results.

## Technologies Used
- HTML
- CSS
- JavaScript
- JSP

## How to Run
1. Install Java JDK.
2. Install Apache Tomcat.
3. Copy the `DayCalculator` project folder into Tomcat's `webapps` directory.
4. Start the Tomcat server.
5. Open your browser and visit:
   
   `http://localhost:8080/DayCalculator/DayCalculator.jsp`
